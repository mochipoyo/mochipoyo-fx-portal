# もちぽよ マーケットポータル

Fincs会員向けのFX情報ポータルです。GitHub Pages で公開し、GitHub Actions で公的データとAIまとめを自動更新します。

- **きょう**：相場時計（いま開いている市場・きょうの予定）、このあとの予定、AI朝のまとめ、政策金利と次の会合、朝のチェックリスト、お知らせ
- **チャート**：TradingViewのチャート（銘柄・時間足の切り替え）、マルチタイムフレーム（日足・4時間足・1時間足・15分足）、マーケット一覧
- **通貨の強弱**：通貨ヒートマップ、クロスレート、投機筋の通貨ポジション（CFTC）
- **金利・中銀**：主要8中央銀行の政策金利と次回会合、会合カレンダー、日米の金利差とドル円、日米の利回り曲線、主要国の10年債
- **経済指標**：経済指標カレンダー（TradingView）、米国の物価・雇用の主要指標
- **ニュース**：AIマーケットまとめ（過去40回分）、週末まとめ、為替ニュース（TradingView）
- **休場・時間**：東京・ロンドン・NYの休場予定、夏時間の切り替え、市場の時間帯、毎日決まった時刻のイベント

## 1. 最初の設置（30分ほど）

### 1-1. 必要なもの

| もの | 用途 | 費用 |
|---|---|---|
| GitHubアカウント | サイトの公開と自動更新 | 公開リポジトリなら無料。非公開リポジトリでPagesを使う場合は有料プラン（GitHub Pro以上）が必要 |
| FREDのAPIキー | 米国の金利・経済指標の取得 | 無料（https://fred.stlouisfed.org/docs/api/api_key.html でアカウント作成後に発行） |
| Claude APIのキー | AI朝のまとめ・週末まとめ | 従量課金（下の「費用の目安」参照） |

### 1-2. リポジトリを作ってファイルを置く

1. GitHubで新しいリポジトリを作ります（名前の例：`market-portal`）。
2. このフォルダの中身（`site/`、`scripts/`、`tests/`、`.github/`、`package.json`、`README.md`）をすべてアップロードします。
   - ブラウザで行う場合：リポジトリの「Add file」→「Upload files」に、フォルダごとドラッグします。
   - `.github` フォルダは隠しフォルダなので、アップロード後に `.github/workflows/update.yml` があるか確認してください。

アップロードした直後に自動で1回動きますが、次の「公開方法の設定」の前なので失敗することがあります。そのままで問題ありません。

### 1-3. 公開方法の設定

1. リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の **Source** を **GitHub Actions** にします。

### 1-4. APIキーの登録

**Settings → Secrets and variables → Actions → New repository secret** で、次の2つを登録します。

| Name | Secret |
|---|---|
| `FRED_API_KEY` | FREDのAPIキー（32文字） |
| `ANTHROPIC_API_KEY` | Claude APIのキー |

どちらかが未登録でも、その部分だけ取得をとばして他は動きます。

### 1-5. 初回のデータ取得と公開

1. **Actions** タブ →「データ更新と公開」→ **Run workflow** を押します。
2. 「AIまとめも作りますか」で `daily` を選んで実行します。
3. 数分後に緑のチェックが付けば完了です。実行結果の画面に公開URL（`https://ユーザー名.github.io/リポジトリ名/`）が表示されます。

### 1-6. Fincsとの連携

1. Fincsの管理画面で、外部アプリ（トークンアクセスリンク）のURLに、1-5の公開URLを登録します（波形トレード道場と同じ仕組みです）。
2. `site/config.js` を開き、次を設定します（GitHub上で鉛筆アイコンから編集 → Commit changes）。
   - `fincsUrl`：未認証の人に表示する「Fincsを開く」ボタンのリンク先
   - `allowedPlanIds`：見られるプランを限定する場合のみ、プランIDを入れます（空なら全プラン）
3. Fincsのリンクから開いて、本編が表示されれば完了です。
4. うまくいかない場合は、Fincsのリンク先URLの末尾に `&gate=debug` を付けて開くと、原因（期限切れ・宛先違いなど）とトークンの中身（aud など）が表示されます。
   - 「宛先(aud)違い」と出た場合は、表示された aud の値を `config.js` の `audiences: ["ここに貼る"]` に入れてください。

## 2. 自動更新のスケジュール

`.github/workflows/update.yml` で次のとおり動きます（GitHubの混雑で数分〜数十分遅れることがあります）。

| 日本時間 | 内容 |
|---|---|
| 月〜金 6:37ごろ | 全データ取得 ＋ AI朝のまとめ |
| 月〜金 9:52ごろ | 全データ取得（日本国債は財務省が9:30ごろ公表） |
| 土 8:17ごろ | 全データ取得（CFTCは金曜夜に公表）＋ AI週末まとめ |
| ファイルを編集したとき | サイトの再公開のみ |

取得元と更新頻度：

| データ | 取得元 | 元データの更新 |
|---|---|---|
| 米国債利回り・FF金利・物価・雇用 | FRED（FRB・BLS・BEA・米労働省） | 日次〜月次 |
| ドル円などの参考レート | FRB H.10（FRED経由） | 週1回（月曜） |
| 日本国債利回り | 財務省 国債金利情報 | 営業日の翌朝9:30ごろ |
| 投機筋の通貨ポジション | CFTC 建玉明細（Legacy・Futures Only） | 週1回（金曜15:30米東部） |
| 政策金利の変化 | BIS（国際決済銀行）、FRBはFRED | BISは週1回 |
| 祝日 | 内閣府、GOV.UK | 年1回程度 |
| 会員確認の鍵 | Fincs | 毎回確認 |

画面下の「データの更新状況」で、各データの最終更新と失敗の有無を確認できます。

## 3. 手で更新するもの

GitHub上でファイルを開き、鉛筆アイコンで編集 → Commit changes で反映されます（数分）。

### お知らせ（`site/data/manual/notices.json`）

```json
{
  "items": [
    { "date": "2026-10-05", "title": "ポータルを公開しました", "body": "毎朝6時半ごろにAIまとめが更新されます。", "link": "https://...", "linkText": "くわしく" }
  ]
}
```
新しいものを上に書きます。`link` と `linkText` は省略できます。表示は最新5件です。空にすると「お知らせ」欄は表示されません。

### 政策金利（`site/data/manual/central_banks.json` の `current`）

- FRBの変更は翌営業日ごろ、その他の中央銀行の変更はBISの統計から1〜2週間以内に自動で反映されます。
- すぐに反映したいとき、または会合後に「結果は未反映」と表示されているときは、その銀行の `current` を書き換えます。

```json
"current": {
  "display": "1.50%程度", "value": 1.5, "lastAction": "利上げ", "delta": 0.25,
  "decided": "2026-10-30", "effective": "2026-11-05",
  "source": "公式発表のURL"
}
```
`lastAction` は「利上げ」「利下げ」「据え置き」のいずれか。据え置きのときも `decided` を会合日に更新すると「未反映」の表示が消えます。

### 年に1回（翌年の日程が公表されたら）

| ファイル | 内容 | 公表元 |
|---|---|---|
| `manual/central_banks.json` の `meetings` | 2028年の会合日程 | 各中央銀行（多くは前年の夏〜秋に公表） |
| `manual/holidays_us.json` | 2028年のNYSE休場・連邦祝日 | NYSE（ICE）、米人事管理局（OPM） |
| `manual/holidays_jp_extra.json` | 年末年始の休業日 | 日本取引所グループ |
| `manual/cftc_schedule.json` | 翌年のCFTC公表日 | CFTC（一覧の最後の日付より後は毎週金曜として扱います） |

日本の祝日（内閣府は前年2月ごろに翌年分を公表）と英国の祝日は自動で取り込みます。

### 表示の設定（`site/config.js`）

サイト名、ティッカー、チャートで切り替える銘柄、マーケット一覧、経済指標カレンダーの国、朝のチェックリストを変更できます。

## 4. 費用の目安

- **GitHub**：公開リポジトリなら Pages・Actions とも無料です。非公開リポジトリでPagesを使うには有料プランが必要で、Actionsの無料枠（月2,000分〜）を超えると課金されます。このサイトの更新は1回数分×月80回ほどです。
- **Claude API**（推測です）：Claude Sonnet 5.5（入力 $2／出力 $10・100万トークンあたり）とWeb検索（$10／1,000回）の料金で見積もると、1回あたり0.2〜0.3ドル前後、月26回ほど（平日の朝＋土曜）で月5〜8ドル程度の見込みです。検索結果の量で変わるため、Claude Console で月の上限額を設定しておくことをおすすめします。モデルは Actions の Variables に `CLAUDE_MODEL` を作ると変更できます（既定 `claude-sonnet-5-5`）。
- **FRED・財務省・CFTC・BIS・内閣府・GOV.UK**：無料。

料金は2026年10月時点の公表値をもとにした目安です。最新の料金は各サービスでご確認ください。

## 5. 公開範囲について（重要）

- GitHub Pages のサイトは、非公開リポジトリから公開しても **インターネット上に公開** されます（GitHub Enterprise Cloud の非公開サイト機能を除く）。
- Fincs会員の確認はブラウザ側で行う方式です。会員以外には本編を表示しませんが、`data/` のファイル（AIまとめを含む）やページのソースは、URLを知っていれば誰でも取得できます。
- 公開リポジトリの場合は、リポジトリ自体（AIまとめの過去分を含む）もGitHub上で誰でも閲覧できます。
- 検索エンジンには載らないよう `noindex` と `robots.txt` を設定しています。
- データまで会員限定にしたい場合は、サーバー側で確認できる設置先（Cloudflare Pages など）への移行が必要です。

## 6. 利用規約・出典表示について

- **FRED**：画面下部と「このサイトについて」に、FRED API利用規約が求める注記と規約へのリンクを表示しています。消さないでください。
- **財務省・内閣府**：公共データ利用規約（第1.0版）に沿って、出典と「加工して作成」を表示しています。
- **CFTC**：出典を表示しています。
- **BIS**：出典と「BISによる公式翻訳ではない」旨を表示しています。BISの条件では、統計を載せることを理由に利用者へ追加料金を求めることはできません。
- **GOV.UK**：Open Government Licence v3.0 の表示をしています。
- **TradingView**：各ウィジェットの下に「提供：TradingView」のリンクを表示しています（TradingViewの表示・リンクは消さないでください）。**有料の会員制サイトでの無料ウィジェットの利用について、TradingViewの規約に明確な記載は見つかっていません。** 心配な場合は TradingView のウィジェット FAQ にある問い合わせフォームで確認することをおすすめします。
- **GitHub Pages**：GitHubの規約では、Pagesを「オンラインビジネスやEC、商用SaaSのための無料ホスティング」として使うことは認められていません。会員向けの情報ページがこれに当たるかは、GitHubの規約（Terms for Additional Products の GitHub Pages の項）をご確認ください。
- **投資助言について**：このサイトは情報提供を目的とし、売買の推奨を行わないように作っています（AIまとめにも推奨表現を禁止しています）。有料会員向けの提供形態が投資助言・代理業に当たるかどうかの最終判断は、顧問弁護士などにご確認ください。

## 7. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| チャートやカレンダーが表示されない | 広告ブロック・トラッキング防止の機能が TradingView を止めていないか |
| 数値が更新されない | Actions タブで失敗していないか。公開リポジトリで60日間動きがないと、定期実行が自動で止まることがあります（Actions タブの「Enable workflow」で再開） |
| AIまとめが失敗する | Actions のログを確認。モデル名やWeb検索ツールの版が使えない場合は、Variables の `CLAUDE_MODEL`、`WEB_SEARCH_TOOL` で変更できます |
| Fincsから開いても案内画面になる | URLに `&gate=debug` を付けて原因を確認（上の1-6） |
| 「会員確認用の鍵を取得できませんでした」 | Actions を一度実行して `data/fincs_jwks.json` を作成 |

## 8. 開発者向け

```bash
npm test                 # 自動テスト（会員確認・データ取得・AIまとめ）
node tests/build-preview.mjs && python3 -m http.server 8080 --directory preview
                         # 架空のデータで画面を確認（http://localhost:8080）
node scripts/update-data.mjs              # 全データ取得（FRED_API_KEY が必要）
node scripts/generate-brief.mjs --mode daily   # AIまとめ（ANTHROPIC_API_KEY が必要）
```

```
site/                 公開されるファイル
  index.html          画面
  config.js           設定
  assets/             app.js（本体）・charts.js（グラフ）・gate.js（会員確認）・app.css
  data/               自動取得したデータ
  data/manual/        手で更新するデータ
scripts/              データ取得とAIまとめ
tests/                テストと架空データ
.github/workflows/    定期実行
```
